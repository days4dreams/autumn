# Style sample

The one-page sample of fonts, colours, buttons and torn-paper edges, agreed
on 20 November 2026. It's kept here as the reference for the real site's CSS.

To rebuild it: `python3 dev/style-sample/build.py`. This writes
`autumn-house-style.html` next to this file. Open that file in a browser.

This folder is a developer file: it is never uploaded to the website.
