# HOW THE FAQS WORK
# Every question on the site lives in this one file. Change an answer here
# and it changes everywhere it appears.
#
#   ## A group heading            (groups appear in this order on the FAQs page)
#   ### A question?               (the answer goes on the lines underneath)
#   show on: home, house          (optional: other pages that show this question)
#
# Pages you can use after "show on:": home, house, family, guide, enquire.
# To show a page's questions, its file has a line like:  <?= faq_list('family') ?>
# Answers can use Markdown: *italics*, **bold**, [a link](https://example.com),
# and a blank line between paragraphs.
